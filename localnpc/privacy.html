Privacy

What LocalNPC does with data, as described in its documentation. This page is a product description, not a legal policy.

What the package does

LocalNPC sends no data about the player. Its only network use is downloading the model files from Hugging Face (huggingface.co) over HTTPS, with the server's certificate checked and each file checked with SHA-256 (and the licence links in the Editor). LocalNPC runs no server of its own; Hugging Face sees the IP address of the computer that downloads. Checked by reading the code; no network capture was made.

  • No telemetry. No LocalNPC server.
  • No account and no API key.
  • Downloads only on a click. The model files are downloaded when you click the download button in the Setup Wizard, the Model Manager or the sample scene. After the models are downloaded, LocalNPC makes no network requests.
  • On the player's PC. Speech recognition and the language model run inside the game's own process; the NPC speaks with the Windows system voice, and nothing is downloaded for it.
