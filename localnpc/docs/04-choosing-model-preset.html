Choosing a Model Preset

LocalNPC provides two pre-tuned model tiers to balance reasoning capability, download footprint, and hardware requirements.

The Quality preset is not available in v1.0. The value still exists so that saved configs load, but a config that uses it fails with a "not available in v1.0" error. Choose Balanced or Fast.

Balanced is the default and recommended preset. Fast is the option for low-end PCs. Balanced's 1.5B model has run in a Windows player build (Mono and IL2CPP, without a window, one PC, one run each). Not measured yet for Balanced: a minimum RAM, a windowed player, a CPU without AVX2, and a download through the Setup Wizard window.

Measured figures: one PC (Intel Core i7-8750H, 16 GB RAM, Windows 11), Unity 6000.3.10f1, Windows player builds (Mono and IL2CPP), one run per figure, LLM step only. Download sizes are the file sizes in the model catalogue, in decimal units as the Setup Wizard shows them: 491 MB (0.5B LLM) or 1.12 GB (1.5B LLM), plus the speech-to-text file below.

Note: In both presets, the speech suite remains identical: Whisper tiny.en speech-to-text (78 MB). No voice activity model is downloaded: v1.0 detects speech with the built-in energy VAD. The voice is the Windows system voice, so there is no voice file to download.

🛠 How to Switch Presets in Unity

  1. Locate your NpcRuntimeConfig asset in the Project window.
  2. In the Inspector, select the preset: Fast or Balanced (a new config uses Balanced).
  3. Open Tools > LocalNPC > Setup Wizard or Tools > LocalNPC > Model Manager.
  4. In the Setup Wizard, select the same preset and click Download & Provision Fast Suite or Download & Provision Balanced Suite (the button names the selected preset) to verify that the corresponding model weights are downloaded to your local cache. If all models of the preset are already installed, the wizard shows Re-verify Suite instead.
