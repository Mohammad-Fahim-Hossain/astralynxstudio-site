2. DOWNLOADED AT FIRST RUN (NOT INCLUDED IN THIS PACKAGE)
==============================================================================

The setup wizard and the model provisioner download these model files from
Hugging Face (huggingface.co), over HTTPS with the server's certificate checked,
and check each file with SHA-256. LocalNPC runs no server of its own; Hugging
Face sees the IP address of the computer that downloads. The files are not part
of this package.
